# Dataset roadmap

| Dataset | Status | Next step |
|---|---|---|
| Synthetic Demo | SYNTHETIC_VALIDATED | Maintain regression fixtures and seven demonstration pages. |
| NHANES 2011–2014 | REAL_CROSS_SECTIONAL_VALIDATED | Preserve published survey-weighted results and cross-cycle evaluation. |
| VCAP V1.0 | REAL_LONGITUDINAL_VALIDATED | Preserve the audited Digit Symbol analysis and future-visit evaluation. |
| OASIS-2 | PLANNED | Start structured MRI feasibility work after VCAP acceptance. |
| UAS CogCF | ACCESS_PENDING | Review registration and terms before considering panel linkage. |
| HRS | FRAMEWORK_ONLY | Execute independently only in an authorized human-operated environment. |
| NACC | ACCESS_PENDING | Define a cohort and request the necessary data products under a DUA. |

REAL_LONGITUDINAL_VALIDATED requires verified real repeat visits, correct elapsed time, executed models and reviewed outputs. PLANNED indicates deferred implementation. ACCESS_PENDING denotes an outstanding access or use decision. Review dataset-specific conditions in [Data access and governance](DATA_ACCESS_AND_GOVERNANCE.md).
