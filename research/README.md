## Source check

Repository links were checked for missing destinations. External links were reviewed against provider pages, official document indexes or publication records on 2026-11-24. Some direct automated requests to HRS, NCHS, ICPSR and the OASIS-3 preprint DOI were refused even though public source or bibliographic records could be consulted. The MIDUS individual study catalog endpoint was rate limited. Its official laboratory documentation supports the assay description. An older NHATS PDF returned 404 and was replaced with the guide currently listed by NHATS. Access statuses refer to future empirical work.
